# PC Connection Mapper

PCや周辺機器のつながりを、カードとケーブルで視覚化する無料Webアプリです。

**Web版:** https://castella-tools.github.io/pc-connection-mapper/

ブラウザだけで利用できます。アカウント登録やPythonなどのインストールは不要です。

## できること

- PC、モニター、キーボード、マウス、USB Hub、Dock、DAC、オーディオIF、ルーター、NASなどを配置
- 機器名、型番、メモ、カードサイズを編集
- USB / HDMI / DisplayPort / LAN / Audio / 電源 / Bluetooth / Wi-Fi などをケーブルとして接続
- ケーブルの種類、表示名、カーブ・直角・直線、接続方向を編集
- グリッド吸着、パン、ズーム、100%表示、全体表示
- Undo / Redo
- `Shift + クリック`による複数選択とまとめて移動
- 選択した機器の複製
- 左揃え / 上揃え / 横等間隔 / 縦等間隔
- 機器の固定 / 固定解除
- ケーブルの表示ラベル位置を調整
- Deleteキーで選択中の機器・ケーブルを削除
- ブラウザ内への自動保存
- JSONによるバックアップ・復元
- PNG画像への出力

## 基本的な使い方

1. 左側の「デバイス」から機器を追加します。
2. カードをドラッグして好きな位置へ配置します。
3. 上部の「機器を接続」を押し、接続する2台を順にクリックします。
4. 機器またはケーブルをクリックすると、右側のプロパティから詳細を編集できます。
5. 構成図が完成したら「PNG出力」で画像として保存できます。

## 新規作成とサンプル

- **新規作成**: 空のキャンバスから作り始めます。
- **サンプル**: PC・モニター・USB Hubなどを配置したサンプル構成を読み込みます。

## キーボード操作

| 操作 | キー |
|---|---|
| 元に戻す | `Ctrl + Z` |
| やり直す | `Ctrl + Y` / `Ctrl + Shift + Z` |
| 機器を複数選択 | `Shift + クリック` |
| 選択中の機器を複製 | `Ctrl + D` |
| 選択中の機器・ケーブルを削除 | `Delete` |
| 表示倍率を100%へ戻す | `Ctrl + 0` |
| 全体表示 | `Home` |
| 拡大 / 縮小 | `+` / `-` |

## データについて

作業中の構成はブラウザの **LocalStorage** に自動保存されます。

構成データはGitHubや外部サーバーへ送信されません。別のPCやブラウザへ移したい場合は「JSON保存」でバックアップし、「JSON読込」で復元してください。

ブラウザのサイトデータを削除すると自動保存データも消えるため、大切な構成はJSONでも保存することをおすすめします。

## PNG出力

「PNG出力」を押すと、配置した機器の範囲を自動的にトリミングしたプレビューが表示されます。「PNGを保存」から画像として保存できます。
