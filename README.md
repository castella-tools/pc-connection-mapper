# PC Connection Mapper

PCや周辺機器の接続関係を、カードとケーブルで見やすく整理できる無料Webアプリです。

**Web版:** https://castella-tools.github.io/pc-connection-mapper/

ブラウザだけで利用できます。アカウント登録やインストールは不要です。

## 特徴

- PC・モニター・入力機器・USB機器・オーディオ・ネットワーク機器などをカードとして配置
- 機器名、種類、型番、メモ、カードサイズを編集
- USB / HDMI / DisplayPort / LAN / Audio / 電源 / Bluetooth / Wi-Fi などの接続を可視化
- カーブ・直角・直線のケーブル表示
- ケーブルの表示ラベル・位置・接続方向を調整
- ドラッグ時のスマートガイドとグリッド吸着
- 複数選択、まとめて移動、複製、整列、固定
- 構成を整理するグループ枠（標準はカード ＞ ケーブル ＞ グループ枠。必要に応じて枠をケーブルより前へ変更可能）（通常 / 背面の表示順を選択可能）
- Dark / Light の背景切り替え（画面・PNG出力に反映）
- サイズ変更できる構成図タイトル
- 自由配置できる注釈テキスト
- カードごとの任意画像（右下寄せの背景画像として表示、濃さ5〜70%で調整可能）
- デバイス検索とカテゴリ折りたたみ
- Undo / Redo
- ブラウザ内への自動保存
- JSONによるバックアップ・復元
- PNG画像への出力

## 使い方

1. 左側の **デバイス** から機器を追加します。操作例を確認したい場合は、上部の **サンプル** からネットワーク回線～PC・周辺機器までをつないだ構成例を表示できます。
2. カードをドラッグして配置します。
3. 接続元のカードを **ダブルクリック** し、接続先のカードをクリックします。上部の **機器を接続** や `C` キーからも開始できます。
4. 機器またはケーブルを選択し、右側の **プロパティ** から内容を編集します。
5. 必要に応じてタイトルやグループ枠を追加します。グループ枠はプロパティから **通常 / 背面** を切り替えられます。左側の **配置 → 背景** から Dark / Light も選択できます。
6. 完成したら **PNG出力** または **JSON保存** を利用します。

## 主な操作

| 操作 | 方法 |
|---|---|
| 機器を移動 | カードをドラッグ |
| 複数選択 | `Shift + クリック` |
| 選択中の機器を複製 | `Ctrl + D` |
| 選択中の機器から接続開始 / 接続モード終了 | `C` |
| カードから接続開始 | カードをダブルクリック |
| 元に戻す | `Ctrl + Z` |
| やり直す | `Ctrl + Y` / `Ctrl + Shift + Z` |
| 選択中の機器・ケーブルを削除 | `Delete` |
| 表示倍率を100%へ戻す | `Ctrl + 0` |
| 全体表示 | `Home` |
| 拡大 / 縮小 | マウスホイール または `+` / `-` |
| キャンバスを移動 | 空白をドラッグ / 中ボタンドラッグ |

## デバイス

左ペインには、以下のカテゴリを用意しています。

- PC・端末
- ディスプレイ・映像
- 入力・操作
- USB・拡張
- オーディオ
- ネットワーク・ストレージ
- 電源
- その他（Textから自由な注釈テキストも追加可能）

PC、スマートフォン、タブレット、ゲーム機、モニター、プロジェクター、KVMスイッチ、キャプチャーカード、映像分配器、左手用デバイス、ONU / モデム、ルーター、Firewall、PoE Switch、Network Camera、NVR、Server、NAS、電話機、各種オーディオ機器、電源機器、Smart Home / IoTなどを用意しています。リストにない機器は `Other` を追加し、表示名を変更して利用できます。

検索欄からデバイスを絞り込めます。カテゴリ見出しはクリックで折りたため、状態はブラウザに保存されます。

機器カードを選択すると、プロパティの **カード画像** から任意画像を1枚設定できます。画像はカード右下へ寄せた背景として表示され、濃さを5～70%で調整できます。左上から右下に向かってフェードするため、濃く設定してもタイトルや種類の文字を邪魔しにくい表示です。**透過PNGを推奨**します。背景付きのJPEG / PNGも使用できますが、画像内の余白によって機器本体が小さく見える場合があります。画像はブラウザ内で最大512px相当に縮小・圧縮して保存されます。

## ケーブル

主な接続種類をカテゴリ分けして用意しています。

- USB / 高速I/O
- 映像
- 音声
- ネットワーク・通信
- 電源
- 無線
- その他

ネットワーク・通信には `LAN` / `PoE` / `Telephone Line`、音声には `Speaker Cable` も用意しています。表示ラベルは自由に変更できるため、`USB-A to C` や `DisplayPort` など用途に合わせた表記が可能です。

## PNG出力

PNG出力時には、以下を設定できます。

- グリッド表示 ON / OFF
- グループ枠表示 ON / OFF
- 解像度 1x / 2x / 4x

出力前にプレビューを確認できます。背景色は構成図側で選択した Dark / Light がそのまま反映されます。

## データ保存

作業中の構成はブラウザの **LocalStorage** に自動保存されます。

構成データは外部サーバーへ送信されません。別のPCやブラウザへ移行する場合や、大切な構成を残しておきたい場合は **JSON保存** を利用してください。

ブラウザのサイトデータを削除すると自動保存データも削除されるため、必要に応じてJSONでバックアップしてください。

## 動作環境

最新版の主要ブラウザを推奨します。

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

構成図の作成や細かな配線調整はPCでの利用を推奨します。スマートフォンでは、構成図の閲覧、キャンバス移動・ピンチズーム、機器追加、基本的なプロパティ編集、機器間の接続など主要な操作を利用できます。

スマートフォンでは画面下部の **デバイス / 接続 / 編集 / 全体** から主要機能へアクセスします。

## プライバシー

PC Connection Mapperは静的なWebアプリです。

入力した機器名・型番・メモ・構成情報は、通常の利用ではブラウザ内に保存され、外部サーバーへ送信されません。
